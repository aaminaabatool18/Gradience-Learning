# Gradience

Gradience is a **web-based learning platform for Computer Science students**, built as a Web Development project.

It provides **AI-powered learning tools, quizzes, flashcards, coding practice, progress tracking, and personalized study support**.

### Tech Stack

* React.js
* Node.js / Express.js
* MongoDB
* Axios

### Features

* AI-generated notes
* AI chatbot tutor
* Quizzes & flashcards
* Online coding environment
* Progress tracking
* Leaderboard
